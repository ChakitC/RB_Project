# ZLZ Anime Toon Character Shader (URP)

### ZLZ Anime Shader is developed based on three core principles

- **Enhancing character visual quality**  
  with a transparent hair system that keeps facial features clearly visible

- **Designed for ease of use**  
  with ready-to-use material setup presets that work with a single click

- **Easy to optimize**  
  by enabling or disabling unnecessary features to support mobile and low-spec devices

---

## Getting Started (Quick Start)

> Recommendation: If you plan to use the **Advanced Setup**,  
> please review the documentation and video tutorials before starting the setup process.

1. Open the `ZLZ_Anime_Shader_Demo` scene located in the `Demo` folder
2. Review the example setup for materials, meshes, and scripts in the demo scene
